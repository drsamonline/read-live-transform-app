# Contributing

This is a **published, copyright work**. It is not an open-source project and it
is **not open for contributions**.

Please do **not** open pull requests, and do not fork and republish the code.
The source is public so that the app can be read and reviewed — not so that it
can be reused.

If you would like to:

- **reuse or adapt** any part of it,
- **translate** it, or
- **report a bug or a factual error** in the text,

please contact the author directly:
