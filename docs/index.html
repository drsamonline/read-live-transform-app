What it does

Six things, kept simple

Every part of the book's own method, turned into something you do rather than only read.

Today

One chapter a day, chosen by the date. The verse is shown, then the day's quest — Read, Live, Transform — with a single button that moves you to the next step, so there is never a wall of choices.

Read

The whole book: the front matter, the twelve parts and all seventy-four chapters — each with its verse card, explanation, practice, questions and takeaway. Write your answers and they save as you type.

Practice

The book's seven-day practice as a checklist, plus My moves — every practice you keep from a chapter, with a daily tap and a count of the days you kept it.

You

Your level and rank, your stats, and ten achievements from First Verse to Whole Book — plus the book's back matter, an export of your practice, and a reset.

Progression

Ranks run E → D → C → B → A → S, each with a title, an XP bar and a day streak. Crossing a threshold opens a level-up panel with your new rank.

Offline & private

One file of about 292 KB with no frameworks, no dependencies and no build step. It installs as a PWA and works with no internet — no account, no analytics, no server.

How it works

The book's method, as a daily practice

One chapter is served each day by the date, so the book unfolds over seventy-four days. Each day is a quest of three steps — and every step you complete earns XP towards a level and a rank.

Read the verse

The day's verse is shown slowly, in the Pickthall translation, with its reference and a careful reading note.

Live the practice

One practice, today — taken from the chapter and kept as a move you can tap off day by day.

Transform by keeping it

Keep the change. Completing all three steps completes the quest and moves you forward.

Get started

Nothing to build

There is no bundler, no package manager and no dependencies. Open the file and it runs.

Use it in the browser

Open the published copy on your phone or desktop, or run the file locally from the repository root:

# from the repository root
python3 -m http.server 8080
# then open http://localhost:8080

Open the app

Install it as an app

A PWA installs to the home screen when it is served over http://localhost or https://. Once installed it opens full-screen and works with no internet.

  • Android / Chrome: menu (⋮) → Install app
  • iPhone / Safari: Share → Add to Home Screen
  • Desktop Chrome / Edge: the install icon in the address bar
  • Desktop Safari: File → Add to Dock

What you'll need

A modern browser from 2021 onward — Chrome, Edge, Safari or Firefox. No account, no internet connection, no install required. The whole app is a single self-contained file, about 292 KB, with its fonts embedded and subset.

Questions

Before you begin

Do I need an account or a connection?

No. There is no account and no sign-in, and the app makes no network requests at all. It works fully offline once you have it.

Where is my data kept?

Entirely on your own device, in your browser's local storage under the key rlt.v2 — your reading progress, kept practices, notes, streak, XP and achievements. Nothing is transmitted anywhere. You → Reset my data clears it all.

Which translation of the Qur'an is used?

The verses are from the English translation of Muhammad Marmaduke Pickthall, The Meaning of the Glorious Koran (1930), which is in the public domain. Every verse and reference in the app was checked against the authentic Pickthall text.

How much of the book is inside it?

All of it — the front matter, the twelve parts and all seventy-four chapters, with each chapter's verse, explanation, practice, questions and takeaway, plus the book's back matter and glossary.

What is it built with?

Plain JavaScript, HTML and CSS in one file. No frameworks, no bundler, no transpiler, no package manager and no dependencies. Offline caching is handled by a small service worker, and the fonts are embedded as subsets.
